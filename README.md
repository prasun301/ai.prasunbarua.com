# Prasun AI

Prasun AI is a modern AI chat platform designed to provide intelligent assistance for learning, coding, writing, research, problem-solving, and everyday questions.

The project is being developed using GitHub and Cloudflare, with a secure backend architecture for connecting the web interface to real AI models.

## 🚀 Features

* Modern AI chat interface
* Real-time AI conversations
* Chat history
* New conversation support
* Dark and light mode
* Responsive desktop and mobile design
* Markdown and code formatting
* Copy responses and code
* Streaming AI responses
* Secure API integration
* File and image support
* Web search capabilities
* Future user accounts and cloud-saved conversations

## 🛠️ Technology

* HTML5
* CSS3
* JavaScript
* GitHub
* Cloudflare Pages
* Cloudflare Workers
* AI API integration

## 🏗️ Architecture

```text
User
  │
  ▼
Prasun AI Web Interface
  │
  ▼
Cloudflare Pages
  │
  ▼
Cloudflare Worker
  │
  ▼
Secure AI API
  │
  ▼
AI Model
```

API credentials will be kept securely on the server side and will not be exposed in the frontend source code.
