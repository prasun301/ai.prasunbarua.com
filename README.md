# Prasun AI

Prasun AI is a modern web-based AI chat platform designed to provide helpful assistance with learning, coding, writing, research, problem-solving, and everyday questions.

The platform provides a clean conversational interface and connects securely to AI services through a server-side API layer.

## 🚀 Features

- Modern AI chat interface
- Real-time AI conversations
- Chat history
- New conversation support
- Dark and light mode
- Responsive desktop and mobile design
- Markdown and code formatting
- Copy responses and code
- Streaming AI responses
- Secure server-side API integration
- File and image support
- Web search capabilities
- Ongoing feature and performance improvements

## 🛠️ Technology

- HTML5
- CSS3
- JavaScript
- GitHub
- Cloudflare
- Cloudflare Pages
- Cloudflare Functions
- AI API integration
